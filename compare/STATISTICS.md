# Statistical design of `compare` (M2)

This is the specification that `compare.calibrate` and `compare.verdict` implement (plan `Planning/MILESTONE_2_PLAN.md`, decisions D2, D3 and D6–D9). The first version was written before any calibration was run. The refinements marked **[refined]** were forced by running it on real ensembles and synthetic suites (see §9); the code is in `compare/stats.py` (kernels), `calibrate.py`, `verdict.py`.

## Inputs

- **Ensemble**: K seeded `ref-1` runs of one input (K = 20 in M2; at least 4 are required). Each run is an `ObservableTable` (`compare/model.py`), held as a per-run *extract* (§7).
- **Candidate**: m ≥ 1 runs of the same input, produced by the code under test (BASIC or C++). The candidate input hash must equal the ensemble's.
- **α = 0.01**: the family-wise error rate of one suite run (D3).

A **field** is a key `(label, index)` inside a family `(file, block, group)`. The **variance group** of a field is its label (the column of a table): fields of one column share a variance law, fields of different columns do not. **[refined]**

## 1. Field classes (D6)

For every key seen in at least one ensemble run:

| Class | Rule | Treatment |
|---|---|---|
| constant | present in all K runs with identical value (bitwise for floats) | a deviating candidate is *one event of the family* with p = 1/(K+1), see below; structural text must match |
| stochastic numeric | numeric, finite, not identical across the K runs | statistical tests (§2–§4). A run where the key is absent counts as 0 (absent table rows are zero yields) |
| zero field | value 0 in every run, and either absent in some run or its column has a stochastic field **[refined]** | statistical, with mean 0 and the group floor (§2): a bin that stayed empty can receive an event |
| ignored | varies but not finite in all runs, a derived label (`dmp` `lo`, `hi`: the trimmed range of the `y` bins), or any varying number of a log-line file (kind `text`: stdout, ctl, input echoes; message counts and nuclide lists depend on the run; their constants stay exact, an absent or unknown line is accepted) **[refined]** | not tested |
| stochastic text | text, not identical across the K runs | not tested, counted in the report |

A family absent from some ensemble runs has all its fields zero-filled in them. A family present in all K runs and absent from the candidate fails (`missing`), **unless its file has a variable family set [refined]**: if the ensemble runs differ in which families the file holds (data-dependent analyzers such as `Zpre(A)`, `Zpost(A)`), the presence of a family is a Bernoulli outcome and K runs showing it is no evidence that it is structural. A missing family there is zero-filled and judged statistically, and its text is not judged.

**Constants of the ensemble [refined].** K identical values do not certify a field as deterministic: by the rule of succession a field constant in all K runs deviates in a fresh run with probability about 1/(K+1) (an edge bin with one event, a conditional mean such as `EcollA` 0.5 or `Z_mean` 60 over a handful of events, the event count of a rare regime, `Control` values in a rare chance regime). So **a deviating constant, numeric or text, is not a hard failure**. All deviating constants of one family count as *one* event of the family (they co-vary in a rare regime, e.g. at 18.5 MeV when the pre-pass has no second-chance fission), and the family's p-value becomes min(p_statistical, 1/(K+1)) (for K = 20, 0.048: Holm at α = 0.01 over thousands of families can never reject on it, but the report lists the family and the constants, and the pooled validity table of G3 includes it). Tolerances inside tables are as before: an absent field is accepted, a present one may differ by one unit of its last printed decimal (`print_quantum`, integers exactly). A deterministic zero that becomes nonzero is judged like a new key (below).

**What stays hard.** Only structure that cannot be a stochastic outcome: (i) a family present in every ensemble run and absent from the candidate (unless the file's family set varies, see above); (ii) a mismatch or an unknown key of *structural text*, the labels in `stats.STRUCTURAL_TEXT` (`dmp`: `title`, `xaxis`, `yaxis`, `version`, `range`: analyzer titles, axis names, the file version, the range line). Nothing else is exact in the statistical verdict. Whether a deterministic *value* is right (a parameter, a barrier, a header number, a constant of the physics) is the job of the exact T1 to T3 comparisons of M3 and later (`compare.exact`), which compare against a reference run of the same seed and not against the spread of an ensemble; the statistical verdict of M2 never claims to certify it.

**New keys and rows [refined].** Keys of the candidate that no ensemble run had are grouped by their index tuple. A key *alone* at its index in a count column (a quantum and a whole number of quanta: a histogram bin nobody filled) enters the statistics with ensemble value 0 and the exact discrete p of §4 (E = 0; bins are independent given the rates, which keeps sparse histograms valid). Several never-seen fields at one index are a **row**: a level that appears in one run only brings E*, Events, J, Upper limit, Yield together (`Isomeric_yields`, keyed by A, Z, E* in eV), a spectrum energy brings Counts, Counts total, Yield norm. together (`Nspectrum`). All never-seen rows of a family are **one event** with p = 1/(K+1) (rule of succession), not one test per field; a spin J = 4.5 is not nine counts. Since the family p is min(p_stat, 1/(K+1)), Holm at α = 0.01 can reject on a new-row event alone only if K ≥ 99 (p = 1/(K+1) ≤ α/m). The symmetric case: keys that *every* ensemble run had and the candidate lacks, in a family whose key set varies between ensemble runs (outside `dmp`, where an absent bin is a zero) are *lost rows*: one event again, and the keys are not tested as zeros. Keys present in some ensemble runs are unchanged: absent counts as 0 (§1 zero-fill), which is a meaningful zero for histogram bins.

## 2. Per-field mean and variance

For a stochastic numeric field i of variance group g: ensemble mean m_i and sample variance s_i² (ddof 1).

**Count-like groups [refined]**: a group with at least 5 stochastic fields, all values ≥ 0, and `var/mean` consistent with φ + ψ·mean (see below): the largest ratio of `var/mean` to φ + ψ·m_i is ≤ 10. Then **v_i = φ_g · m_i + ψ_g · m_i²**. φ_g absorbs the event count and every common-mode effect that scales like counts; **ψ_g ≥ 0** is the run-to-run scale factor: a perturbed parameter set or a different run size multiplies all counts of a histogram by one factor, whose variance (ψ ≈ the variance of the factor, 0.01–0.04 for 10–20 %) grows with m². Robust fit over the well-populated fields (nonzero in ≥ 5 runs; ≥ 20 of them, else ψ = 0 and φ is the median of s_i²/m_i): ψ is the slope of s²/m against m between the lowest and the highest quartile of the means (medians of both coordinates), φ the median of s²/m − ψ·m (not below 5 % of the lowest quartile's median ratio). Columns of conditional means (zero in empty bins, a typical value elsewhere) fail the dispersion test and fall under the next case.

**Per-cell dispersion [refined]**: the column model must never under-state a cell's own spread (perturbed parameters act on single bins; `A_Ekin` cells of a `.ptb`, `Isomeric_yields` `J` rows, `NmultA`, `Nspectrum`, some `dmp` analyzers have a variance/mean of 10–15 in single cells while their column's median is 1). For a count-like field that is nonzero in at least 5 runs, **v_i = max(φ·m_i + ψ·m_i², c·s_i²)** with c = 1 (`SAMPLE_C`). A field whose sample term wins (c·s_i² > the model), and every well-populated field of a column that is not made of counts (v_i = s_i² unless a floor raised it), is judged by **its own sample variance with a Student t law**: z_i = (c̄_i − m_i)/sqrt(s_i²·(1/m + 1/K)) is a t variable with K − 1 degrees of freedom (K − 2 in the leave-one-out draws, where the ensemble has K − 1 runs), and enters D and M as its *normal equivalent* sign(z)·Φ⁻¹(1 − P(|t| > |z|)/2) (`t_equivalent`, bounded by about 37). This keeps the discrete path consistent: low-count fields (§4) carry their own exact p and are unaffected. The price is sensitivity: a quiet cell is no more sensitive than its column, and a cell with 19 degrees of freedom needs about a 3.8σ deviation for p = 10⁻³, 6σ for 10⁻⁵.

**Other groups**: v_i = s_i². If the group has any zero entry (*zero-inflated*), v_i ≥ μ̃_i² · p̂(1 − p̂) with μ̃_i the mean over the nonzero runs and p̂ = (n_nonzero + 1)/(K + 2): a bin filled in every run can still be empty in the next.

**Sparse fields [refined]**: a field nonzero in fewer than 5 runs has v_i ≥ the group floor.

**Zero variance never survives [refined].** A variance that comes out as 0 (a column constant in a leave-one-out ensemble, φ = 0 when most fields are constant) is replaced by the floor of its group; if the family has no floor at all the field is not testable (NaN, the leave-one-out draw is invalid). An infinite z therefore never arises from a zero variance estimate.

**Group floor** [refined] (the variance of a field of the group not seen nonzero): count-like group: max(10 % quantile of its positive v, q²/K), q the 10 % quantile of the fields' nonzero means; other groups: (largest |value| of the group)²/K. A group without a floor uses the smallest floor of the family. (The first version used the smallest positive v of the family, which a single rounding artifact of 10⁻⁶ among yields of 0.5 turned into z ≈ 10⁵.)

## 3. Statistics of one family

With the candidate mean c̄_i over m runs:

z_i = (c̄_i − m_i) / sqrt(v_i · (1/m + 1/K))

- **Global**: D = Σ_i z_i² over the n stochastic fields, plus the zero fields and new keys where the candidate is nonzero.
- **Local**: M = max_i |z_i| over the same fields.

## 4. Null distributions (D8): leave-one-out moment matching

For each ensemble member j: compute D_j and M_j treating run j as the candidate (m = 1) and the other K − 1 runs as the ensemble, using §2 on those K − 1 runs (a field constant in the K − 1 runs uses the full-ensemble variance). The field set and the variance groups are those of the full ensemble. This gives K draws of each statistic under the null, with all of BASIC's common-mode noise included.

- **Global [refined]**: D = (leading mode)² + rest. The leading mode is the top singular direction of the K standardized z vectors; its squared projection is a σ²·χ²₁ (a shared shift of all fields: heavy tail), the rest is a · χ²_ν by moment matching of D_j − mode_j. Both variances are taken on their upper side (mean + 2 standard errors of the K draws). The amplitude of the mode (unit variance) is a scaled Student t with K − 2 degrees of freedom, not a normal: a shared factor is estimated from K runs only, so a fresh run's amplitude in units of the ensemble's spread is a t variable (this is what makes the p-value valid across ensembles when the K sampled factors happen to scatter little). p_global = P(σ²x² + aχ²_ν ≥ D) by quadrature. A single scaled χ² (the first version) underestimates the tail of D by orders of magnitude when the shared pre-pass dominates, and gave about 5 % suite false alarms on synthetic data.
- **Local [refined]**: the z_i are treated as a scaled Student t with variance κ² = mean over the draws of z² and kurtosis equal to the observed mean z⁴/κ⁴ (ν = 4 + 6/(kurt − 3), between 4.1 and Gaussian). If most of the family's variances are sample variances (non-count groups), or the largest count-like group is overdispersed (ψ·median(m) ≥ φ), ν ≤ K − 2. **The local law is that of the dense fields with the leading mode removed**: the leave-one-out z of the dense fields (not low-count ones) are projected on the leading mode of the *other* draws (leave-one-out, so that the residual keeps its noise), the law κ², ν is fitted to the residuals, and a candidate's dense z are projected on the mode of all draws before M is taken. The mode belongs to the global test; left in, it made the local law so heavy that a single shifted bin could not be seen. p_local = 1 − (1 − P(|z| ≥ M))ⁿ (Šidák over the n tested fields: the stochastic ones plus the nonzero zero fields and new keys).
- **Family p-value**: p_F = min(1, 2 · min(p_global, p_local)).
- **Degenerate families [refined]**: fewer than 30 stochastic fields (a global statistic needs many), or no variance of D. Only the local test is used and p_F = p_local. κ² and ν come from the pool of all degenerate families of the same file kind (sums of z², z⁴ over their draws; the median over all families if fewer than 500 draws).

The leave-one-out draws come from K − 1 runs while the real verdict uses K. The (1/m + 1/K) term in z_i accounts for the difference in the mean's uncertainty; G3 measures whether the remaining approximation holds.

**Low counts [refined]**: a count-like column whose nonzero values are whole multiples of a quantum q (the smallest positive value; ≥ 99.5 % within 0.02 quanta; q = 1/events for the `dmp` histograms) and whose Fano factor φ/q ≤ 3 is a *discrete* column. A field of it with an ensemble mean ≤ 20 counts per run is not judged by z. Given Poisson rates, the candidate's count c (over m runs) and the ensemble's total E (over K runs) are conditionally binomial, c | c+E ~ Binomial(c+E, m/(m+K)); this also carries the uncertainty of a rate known from a few events. The p-value is min(1, 2·min(P(X ≥ c), P(X ≤ c))), raised to 1/F with F = max(1, φ/q + ψ·n) the dispersion at n expected counts (conservative: discrete; a negative binomial with that dispersion would be the exact tail, p^(1/F) is the used approximation), and the field's score in D, M and the leave-one-out draws is its normal equivalent Φ⁻¹(1 − p/2). A bin the ensemble never filled (zero field, new key of a known discrete column) is the case E = 0: one event is p = 2/(K+1), three events 2/(K+1)³ (the Gaussian treatment gave about 4σ for one event and p ~ 10⁻⁸ for three). The local test combines two parts: the fields judged by the fitted t law (κ², ν from the well-populated fields only) and the low-count fields judged by the largest normal-equivalent score with an exact Šidák term; the family's local p is the Šidák combination of the two.

Further details of the low-count path [refined]:

- **Quantum hint.** A histogram column with few stochastic fields cannot show its own quantum, but the normalization (1/events) is the same for every analyzer of a file. Families are processed biggest first and a small column inherits the median quantum of the same label in the larger families if its positive values are whole multiples of it (Fano 1). Whole-number detection only uses ratios ≤ 1000 quanta (printed digits cannot tell larger ones from integers), needs ≥ 5 of them for a column's own quantum, and accepts 99.5 % within 0.02 quanta.
- **Run-size normalization.** The candidate's share in a bin is scaled by its histogram size against the ensemble: weight m·(candidate events / ensemble mean events) over the discrete columns, clipped to [0.2, 5]; in the leave-one-out draws each run's size against the mean of the others. A shared normalization (a perturbed parameter set, more events) must not look like excess events in the tail bins.
- **Clustering factor.** Events of one family can come in clusters; the squared deviations of the low-count fields from their ensemble mean over their Poisson expectation, summed per file kind (never below 1), are stored in the calibration (`clustering`), and the exact Šidák p of the low-count fields is raised to 1/clustering.
- **Non-count floor.** An unseen field (a zero field or a new key) in a column that is *not* made of counts has no one-event scale: its floor is (largest |value| of the column, deterministic fields included)²/K. Without it a field that was 0 in all runs and 0.0025 in a candidate (an isomer row, a yield of 10⁻³ next to constants of 10⁻⁶) came out at z ≈ 10⁵.

## 5. Suite verdict (D3)

Holm step-down at α over all statistically tested families: the family of rank r (1-based, by p_F) out of F rejects if p_F ≤ α / (F − r + 1) and every lower rank rejected. **F [refined] is the number of families judged that have numeric fields** (every such family gets a p-value, 1 when nothing in it is testable), not the number with p < 1; with the smaller F the thresholds would be too lax. `--holm-total calibration` uses the calibration's family count when only some files are judged. Hard failures (`missing` families, structural text, §1) always reject; a deviating constant never does on its own (p = 1/(K+1), §1). F includes the families whose only content is such constants. The suite **passes** if nothing rejects.

## 6. Minimum detectable effect (G5)

For family F with n fields, the local test rejects a single-field shift δ at field i when |z_i| ≥ t*, where t* solves 1 − (1 − P(|z| ≥ t*))ⁿ = α / F under the local null of §4 (Holm's first, strictest step). The MDE in value units is t* · sqrt(v_i · (1/m + 1/K)), and relative to the field it is that divided by m_i. `compare.calibrate` writes the MDE of every field of the families the injection tests use (`--mde FILEGLOB::BLOCKGLOB`; default `Apost.dmp`/`APOST` and ENDF `MF8/MT454`) and `Calibration.mde(family, m)` computes it for any family on demand. Deterministic fields have MDE 0. **Fields judged by their own sample variance** (the t law of §2) are scored by the normal equivalent of a t with K − 1 degrees of freedom, which saturates; their MDE is the shift that reaches t* in that score, `student_isf(Φ(−t*), K − 1) · sqrt(s² (1/m + 1/K))` (`mde_own_values`), infinite where t* lies beyond what the score expresses (p < 1e-300). With t* ≈ 20 (thousands of fields, Holm over 40 000 families, heavy local tail) this is of order 10⁵ sample standard deviations: such a field is practically undetectable alone, and the linear formula would have claimed a MDE of 20 σ for it (a shift of 110 σ was scored 11 and not rejected).

## 7. Memory and scale, artifacts

A full 59-energy Rn-215 run has tens of millions of observables. Nothing holds a run as `dict[Key, Value]`:

- `compare.extract` streams each file from its parser into per-family arrays (interned labels, int64 key matrix, float64 values; text separately), content-addressed key layouts shared by all runs of an input, one `.npy` of values per file (memory-mapped), cached under `build/compare/extract/` and keyed by the size and mtime of every run file plus the parser sources;
- calibration, verdict and injection process one file at a time and, inside it, one family at a time (K runs aligned by unique rows);
- the calibration artifact stores per-family arrays per file (`compare/calibrate.py` docstring has the layout).

## 9. Changes against the first version, and known weak spots

Reasons, in the order they were met on real data (`m1_cf252_gs` ensemble, held-out `m1-g4-cf252-ref1-independent`): columns of one table mix scales (yield, mean A, uncertainty) so φ per family is meaningless → groups per label; one rounding artifact set the family floor → group floors; conditional-mean columns (mean TKE, mean spin) are not Poisson-shaped and empty at the edges → dispersion test, zero-inflated and sparse rules; printed digits and rare analyzers made "identical in K runs" fail a new run → tolerance, absent zero, unseen families; mean z² as κ² was dominated by a few outlier families (10⁸) → kurtosis-fitted t and pools by median or by degenerate families; D far in the χ² tail with a shared mode → mixture; p-values of tiny discrete families → ≥ 30 fields for a global test.

Rare analyzers and chance constants (Rn-215 short, K = 12): the exact failures `Zpre(157)`, `Zpre(58)`, `Zpost(63)`, `Zpre(152)`, `Zpre(63)` (`ZApre.dmp`/`ZApost.dmp` hold one block per fragment mass A that received events; the edge masses appear in some runs only, here in all 12 by chance), `EcollA y[58]`, `y[157]` (XE.dmp: mean collective energy 0.5 in the bins with a single event) and `Z_mean (post)[151]` (out file: 60 in all runs, 59 in the candidate) were all constants of K runs. They are now variable-file and pinned cases (see §1). Before: `m1-g23-rn215-n-a` 7 exact failures, `m1-g1-rn215-ref1` 1; after: 0 exact failures in both.

Single-event bins (Cf-252, `m1_cf252_gs`, K = 17–19): the three leave-one-out failures of the first dry run (`EexcL2dheavy(189)`, `(308)`, `(280)`, `(175)` in `Eexc.dmp`) were all bins with one or two events in the ensemble and three in the candidate, scored z ≈ 6 and p ~ 10⁻⁷ to 10⁻⁸ under the Gaussian law; the conditional binomial gives p ≈ 2·10⁻³ for that bin. `test_discrete.py` checks `P(p ≤ t) ≤ t` for t = 10⁻⁴ … 0.1 on sparse Poisson histograms (expected counts 0.005 … 1500) and detection of six events in a bin of 0.1 expected.

Over-dispersion (Cf-252 `loo-s2006`, `tmp/*.ptb` `Prompt_results/TXE` `Counts[70..77]`): counts 3–4 times the ensemble's in the tail while the ensemble's own `var/mean` is Poisson-shaped in the bulk. A `.ptb` file is one perturbed-parameter pass, so the parameter spread multiplies the counts; φ·m cannot hold at m ≈ 10³ and the column failed the dispersion test. v = φ·m + ψ·m² fixes both: the column stays count-like and its large fields get the right variance. `test_discrete.py` pools 16 calibrations × 40 suites with a lognormal run factor of 10 % and 20 % (dense histograms of 50–5000 counts per bin) and a 15 % lognormal size factor on sparse ones, and checks `P(p ≤ t) ≤ t` within binomial noise at t = 10⁻³ … 0.1; validity is across ensembles (an ensemble whose K factors scatter little is invalid on its own, which the t amplitude accounts for). With a 30 % factor the p-values are conservative at 0.01 (0.96 %) but not at 10⁻³ (0.44 %; before the change 1.9 % at 0.01): documented limit.

Constants and per-cell dispersion (Rn-215 short, K = 20, leave-one-out): with the constants as hard failures, a run in a rare regime failed alone through `events`, `Control` text and a few `lo`/`hi`-like constants (s1001 at 18.5 MeV: 29 exact failures; s1009: 131 `events[1]` mismatches in `dmp`; s1008 at 30 MeV), and 12 more suites through single cells of 2D tables (`A_Ekin`), `Isomeric_yields` rows, `NmultA` and `Nspectrum` whose per-cell dispersion the column model understated. Both are now treated as above; `test_discrete.py` pools 16 calibrations × 40 suites of dense histograms whose cells scatter by their own lognormal factor of 0 to 30 % and checks `P(p ≤ t) ≤ t` at 10⁻⁴ … 0.1.

Open at the end of this round (Rn-215 short, K = 20, `build/compare/g3_rn215_C`): 9 of 22 suites fail. Classes, with evidence: (1) a run in the rare 18.5 MeV regime (`s1001`, 128 families: all `APRE`/`NMPRE` bins shifted by 10 % at once, 7.81 against 7.07 to 7.16 in the other 19) is a K = 20 ensemble's one outlier; (2) `Isomeric_yields` rows keyed by E* (6 suites): a level that appears in one run only brings a whole row (`E*`, `Events`, `J`, `Upper limit`, `Yield (%)`) of new keys, each judged on its own against the column floor, instead of one new row; (3) `Nspectrum` `Counts[<energy in eV>]` rows: the index is a value, the same new-row effect; (4) `NmultA` and a few `mvd`/`dmp` cells with single-run spikes. Nothing was loosened to hide these; see the report of the run.

Known weak spots, to be measured by G3 with K = 20:

- every tail p-value (10⁻⁶ and below) is an extrapolation from K = 20 draws; the variance safety margin and the t tail make it conservative but not exact;
- columns of conditional means have a very low sensitivity (occupancy variance), the conditional means are covered through the yields in other files;
- low-count fields assume Poisson counts with a dispersion F ≤ 3 at 20 counts; a column more overdispersed than that stays on the Gaussian path with its sparse-variance floor;
- the local law of the dense fields is fitted on a few hundred residuals, and extrapolating its tail to p ~ 10⁻⁵ per field is not resolved by the data (the kurtosis fit is the only guide).

**Round-off variance in leave-one-out draws.** K − 1 identical printed values (a table that every run but one prints identically) leave a computed variance of order 1e-27, not 0; `_loo_moments` snaps variances below `(CONSTANT_RTOL · peak)²` (`CONSTANT_RTOL = 1e-10`) to 0 so that the constant-in-the-others rule (the full-ensemble variance replaces it) applies. Without it the draw that leaves out the one different run (the rare-regime run s1001: `EMpot`, `XE.dmp` at 18.5 MeV) gave z² ≈ 1e32 and made the pooled local null of every `dmp` family without a global test κ² ≈ 1e27, i.e. their local test blind.
