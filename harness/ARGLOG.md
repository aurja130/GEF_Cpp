# Argument log (`probes/arglog/`)

The `arglog` patch (M5.1, `Planning/MILESTONE_5_PLAN.md` D2) records the arguments, ByRef values and results of the calls GEF makes to the deterministic physics functions that M5 ports, and the inputs and outputs of the two deterministic pieces M5 extracts from larger code (the `P_Egamma_low` cross-section table and the E2 rotational cascade). The FreeBASIC drivers and the C++ tests replay these calls; the logged results are a second, in-context oracle.

## Building and running

| What | How |
|---|---|
| Patch | `harness/patches/arglog.patch`, generated by `python3 -m harness.arglog_patch` (`--check` compares with the committed file; a pytest test does too). Do not edit it by hand |
| Build | `python3 -m harness.build m5-arglog --define GEF_ARGLOG` (patch set `m5-arglog` = `seed`, `scope`, `arglog`) |
| Without `-d GEF_ARGLOG` | The patch adds no code: every addition is inside `#ifdef GEF_ARGLOG`. The C fbc emits for the patch set equals the `seed` + `scope` emission apart from fbc's source-echo comments (checked with `emit_c`, `#line` markers included), so line numbers are kept |
| `GEF_ARGLOG_MAX` (run time) | K, the number of calls logged in full per function or site; default 100000. `0` logs nothing |
| `GEF_ARGLOG_SPREAD` (run time) | `1` (default): beyond the first K calls, call n is logged if it is a multiple of 2^j, where K·2^(j-1) < n ≤ K·2^j, i.e. about K/2 more records per doubling of the call count, spread over the whole run. `0`: only the first K calls |
| Inspect | `python3 -m harness.arglog summary <work>/probes/arglog [--json]` |

The logs are written to `probes/arglog/` in GEF's working directory with POSIX `open`/`write` and static buffers: no FreeBASIC file numbers (GEF's `FreeFile` results do not change) and no heap allocation. Each file is created at its first logged record; `_counts.txt` is written when the program ends (module destructor, which also runs on `End`).

## How calls are intercepted

`harness_arglog.bi` (included at `GEF.bas:695`) holds the logging runtime. `harness_arglog_wrappers.bi` (`GEF.bas:1820`, after `Dim Shared f` and before the first call at 2119) defines one wrapper `hlog_<name>` per function, which calls the original exactly once with the same arguments and returns its result unchanged, and then a function-like macro `#define <name>(...) hlog_<name>(__FILE__, __LINE__, ...)`. Every call after that point goes through the wrapper. fbc rejects a `#define` whose name is a declared procedure ("Duplicated definition"); a preceding `#undef` removes the symbol, and the wrappers, compiled before, keep calling the procedure (same C name).

Each definition is bracketed by `#undef <name>` and `#undef`/`#define <name>`, so a function is not renamed inside its own body; the calls it makes to the other functions are logged. The inserted directives are followed by `#line N-1`: after `#endif`, fbc's `#line N` makes the following line N + 1 (after an `#include` it does not; the other harness patches use `#line N` after an `#include` and are correct).

`U_Q_beta_minus` is declared and defined in `DCLbranchingJEFF33.bas` (included at `GEF.bas:1284`): its wrapper is included at line 111 and its macro at line 116, so its calls in that file (lines 124, 134) and in `Branchings.bas` are logged.

Wrappers take the parameters with the declared types, so a call converts its arguments exactly as the direct call does (e.g. `U_levdens(Z As Integer, …)` called with a `Single`); the log shows the converted values.

## Limits

- **Spread records are not a uniform sample.** Beyond the first K calls, call n is kept when n is a multiple of 2^j. A statement that calls a function an even number of times per pass (e.g. `Beta_Equi`'s two `LyMass` calls at `GEF.bas:16614-16615`, `FEDEFOLys`'s two calls at 16213) then keeps almost only one of them: after the first 20,000 calls the two `LyMass` sites of `Beta_Equi` are logged 26,206 : 994 times (Rn-215). The first K records are complete and unbiased; argument ranges taken from the spread records (`summary`) are a lower bound of what GEF reaches.
- **Calls made before `GEF.bas:1820` are not logged.** `DCLbranchingJEFF33.bas` (included at `GEF.bas:1284`) calls `AME2020` twice inside `U_Q_beta_minus` (line 113); those calls bypass the `AME2020` wrapper, so `AME2020.txt` and its count in `_counts.txt` leave them out (2 × 118,656 calls in Rn-215). `U_Q_beta_minus` itself is logged.
- **Call-site line.** `__LINE__` is the line where the call's argument list closes, so a call continued over several lines is logged at its last line (e.g. `De_Saddle_Scission` at `GEF.bas:6318-6319` as 6319). Files included more than once (`Branchings.bas`, `Plotting.bas`) give the same call site for every inclusion.

A site record is opened at the entry (its call-site field is the first line of the piece) and completed at the exit; the fields are named `in.<expr>` and `out.<expr>`. `out.Array_Eg2_<side>(1..Ig2_<side>)` lists the stored gamma energies (clipped to `UBound`); `out.sigma(0..UBound)` is a hash of the table (below).

## File format

One ASCII file per function or site, `\n`-terminated lines. The first line is the header:

```
# arglog 1 <name> <field>:<type> <field>:<type> ...
```

Functions: the parameters in order, a ByRef parameter as `<name>.in` and `<name>.out`, then `result` (not for a `Sub`), then `global.<name>` for shared variables the function reads (`Beta_Equi`: `global.f`, the file number of its non-convergence `Print #f`). Every following line is one call:

```
<seq> <step> <pass> <event> <file>:<line> <value> <value> ...
```

| Field | Meaning |
|---|---|
| `seq` | 1-based number of the call among all calls of this function or site (logged or not); strictly increasing in the file |
| `step`, `pass`, `event` | `Harness_Step`, `Harness_Pass`, `Harness_Event` of the `scope` patch at the time the record is written |
| `file:line` | The call site in the original numbering, file name without directory |

| Type | Token |
|---|---|
| `f32` | The `Single`'s bits, 8 lowercase hex digits |
| `f64` | The `Double`'s bits, 16 lowercase hex digits |
| `i64` | The `Integer`, two's complement, 16 lowercase hex digits |
| `u8` | The `UByte`, 2 lowercase hex digits |
| `str` | The bytes of the string in hex, `-` if empty |
| `f32[]` | `<count>` or `<count>:<bits>,<bits>,...` |
| `f32hash` | 16 hex digits: h = 0xCBF29CE484222325, then h = (h xor bits) · 0x100000001B3 (mod 2⁶⁴) over the `Single` elements in index order |

A function record is written when the call returns, so the records of nested calls of other functions come first in their own files; no logged function calls itself.

`_counts.txt`: header `# arglog 1 _counts name calls max spread`, then `<name> <calls> <K> <spread>` for every function and site, including those never called. `harness.arglog summary` checks that each file holds exactly the calls the sampling rule selects (`complete=True`).

## Neutrality

Proven like the other patches: the same seed gives byte-identical output with and without `-d GEF_ARGLOG` (timestamps masked, `probes/` allowed only in the patched run). Evidence: `Planning/MILESTONE_5_PLAN.md`, completion notes of M5.1.
